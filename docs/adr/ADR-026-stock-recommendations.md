# ADR-026: 국장 개별 종목 추천 (단·중·장기 Top 픽)

## Status

Accepted (2026-06-18)

## Context

기존 surface는 지수(코스피200 사다리)·섹터·종목분석(롱/인버스)을 다루지만, 사용자가 실제로 묻는 "그래서 **어떤 개별 종목**을 사야 하나(삼성전기·현대건설·SK하이닉스 등)"에는 답하지 못했다. 사용자는 **국장 개별주를 단기·중기·장기 3구간으로 나눠 각 구간 Top 3~5종목을 추천**하되, 사이트의 많은 정보(에이전트·뉴스·섹터·하우스 뷰)와 결합해 **합리적이면서 과감하게** 추천해달라고 요청했다(면책 고지가 있으므로 과감 허용).

제약: 결정론·정직 소싱·표시전용·float 금지. 추천은 모델 산출 참고 의견이며 투자자문이 아니다(면책).

## Decision

**커리큘럼화된 유니버스를 실 종목 모멘텀 + 사이트 컨텍스트로 점수화해 horizon별 Top 픽을 내는 결정론적 추천기**를 둔다.

1. **유니버스**(`domain/stocks/universe.py`). 30개 대표 국장주(삼성전자·SK하이닉스·삼성전기·현대건설·현대차·POSCO·LG화학·삼성SDI·에코프로비엠·NAVER·카카오·삼성바이오·KB금융·한화에어로·두산에너빌리티·HD현대중공업·HMM 등)에 메타데이터: 라이브 Yahoo 심볼(검증됨), 보드 정렬 `sector_key`(8섹터), 구조적 `themes`(AI반도체·HBM·2차전지·방산·원전·조선·CDMO 등), `rate_sensitivity`(매파 BOK 영향: BENEFIT 은행/HIGH 성장주·건설), `beta`(국면 민감), 뉴스 `aliases`(촉매 탐지).
2. **신호 수집**(`agent_service/stock_service.py`). 30종목 일봉(키리스 Yahoo)을 **병렬 수집**해 20/60/120일 모멘텀·이평선 상회를 계산하고, 사이트의 **하우스 뷰**(최신 예측 direction/regime/BOK), **라이브 섹터 보드**(시장 분석), **최근 뉴스 헤드라인**을 결합해 `StockSignal`을 만든다. never-fails(수집 실패 종목은 테마/정책 기반 점수). TTL 캐시.
3. **결정론 추천기**(`domain/stocks/recommender.py`). horizon별 투명한 선형 점수:
   - **단기**: 20일 모멘텀(주) + 이평선 + 섹터 당일 강세 + 뉴스 촉매 + 국면·베타.
   - **중기**: 60일 모멘텀 + 추세 + 하우스 방향 + **BOK 조정**(매파→은행 가점/성장주 감점) + 테마.
   - **장기**: 120일 추세 + **구조적 테마 가점**(AI반도체·2차전지·방산·원전 등) + BOK + 국면.
   각 horizon Top 5, 확신(`적극매수`/`매수`/`관심`) + 근거(한국어 드라이버) + 뉴스 촉매. 클리핑으로 점수 유계.
4. **읽기 라우트**: `GET /api/v1/stocks/recommendations` → `StockRecommendationReport`(하우스 컨텍스트 + 3 horizon × Top5 + 면책).
5. **UI**: `/stocks` "종목 추천" 페이지(컨텍스트 스트립 + 3 horizon 섹션, 각 종목 랭크·확신배지·모멘텀·테마·근거·뉴스촉매), nav "종목추천"(Sparkles)·홈 배너.

## Consequences

- 사용자는 "지금 어떤 개별주를" 단·중·장기로 본다. 실 모멘텀 기반이라 즉시 유용하고, 사이트의 예측·BOK·섹터·뉴스가 모두 한 점수에 반영된다. 라이브 검증: 단기=삼성전자·SK하이닉스·삼성전기·NAVER·한화오션, 장기=반도체(AI·HBM)·두산에너빌리티(원전)·HD현대중공업(조선) 등 합리적·과감한 픽.
- 결정론·정직 소싱·표시전용·float 미사용 유지. 면책을 UI/스키마에 명시(투자자문 아님).
- 한계: 모멘텀·테마·정책의 휴리스틱 선형결합이라 펀더멘털(밸류·실적 추정)·수급 실데이터는 미반영. 후속으로 실적·수급 신호를 같은 `StockSignal`에 추가할 수 있다.

## Update (2026-06-18b) — 과열/버블 페널티 + 클릭 상세

순수 모멘텀 보상은 "이미 너무 오른" 종목(=고평가·버블 가능성)을 무조건 상위로 올리는 문제가 있었다. **추세 이격(120일선 대비 %)을 과열 지표**로 추가해, 임계 이상으로 과열된 종목에 **horizon별 페널티**(단기 최대 / 중기 / 장기 최소 — 구조적 성장은 프리미엄을 지속할 수 있으므로)를 적용하고 **과열 플래그·"되돌림 위험" 근거**를 노출한다. 결과: 라이브에서 SK하이닉스(이격 +105%, 모멘텀 최고)가 과열로 강등되고 이격 낮은 NAVER·HMM이 상위로(추세 지속과 되돌림 위험의 균형). 또한 각 픽에 **horizon별 상세 근거(`detail`)**를 담아 UI에서 종목 클릭 시 펼쳐 보이게 했다(모멘텀·섹터·테마·BOK·과열·뉴스를 문장으로 설명). 한계: 이격은 *기술적* 과열 프록시이며 펀더멘털(PER/PBR) 밸류는 미반영 — 후속 과제.

## Alternatives Considered

- **LLM로 종목 추천 생성(considered, not chosen).** 풍부하나 비결정론·환각·비용. 결정론 점수 + 한국어 근거로 시작.
- **사다리(지수 ETF)만 유지(rejected).** 사용자가 명시적으로 개별주를 요구.
- **섹터 다양성 강제 디버전스(rejected).** 반도체가 모멘텀 최상위인 건 실데이터의 진실. 인위적 분산은 정직성을 해친다(면책으로 과감 허용).
