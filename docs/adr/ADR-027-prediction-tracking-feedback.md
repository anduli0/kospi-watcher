# ADR-027: 예측 추적·채점·자동 피드백 보정 (예측 vs 실제 시계열 + 자기개선 루프)

## Status

Accepted (2026-06-18)

## Context

ADR-025에서 추세 신호의 정확도를 백테스트했지만, 사용자는 더 나아가 (1) **이 프로그램의 예측과 실제가 어떻게 진행돼 왔는지 기록**하고, (2) **두 시계열을 그래프로 직관 비교**하며, (3) **그 오차를 채점·평가해 예측을 자동 개선하는 피드백 루프**까지 요구했다.

핵심 통찰: 이 시스템의 방향 예측은 **결정론적**(주 드라이버 `trend_core`는 과거 한정·재현 가능)이므로, 과거 각 날짜에서 모델이 무엇을 예측했을지 **replay**해 실제 결과와 정직하게 비교할 수 있다. 별도 누적 DB 없이도 추적 기록이 항상 최신으로 재구성된다.

## Decision

**예측을 과거 전 구간에 replay해 실제와 비교·채점하고, 그 채점에서 도출한 보정(Calibration)을 합성기에 되먹여 다음 예측을 자동 개선**한다.

1. **추적·채점**(`domain/prediction/accuracy_track.py`, 순수). 일봉(날짜 포함, `infrastructure/marketdata/history.fetch_daily_dated`)을 받아 1년 창의 매일 `trend_core`를 replay → 예측 방향. 두 누적수익 곡선을 만든다: **실제(지수 매수보유)** vs **모델(예측 방향 추종)**. D5 forward로 방향 적중을 채점: 적중률, `naive=max(up,1-up)` 기저율, 스킬, 상승/하락 예측별 적중(표본 0이면 N/A), 커버리지, 누적수익. 미래 정보 미사용.
2. **자동 피드백 보정**(`Calibration`). 채점에서 유계 보정 도출: **방향 보정**(`direction_bias`, ±0.08; 실현 추세 방향으로, 기저율 미달분에 비례해 가산) + **신뢰도 보정**(`confidence_scale`, 0.8~1.12; 모델 강도-함의 확신 대비 실적중률로 과신/과소 교정). 정직한 등급(B+ 기저율 상회 / B 기저율 수준 / C 미달; A 없음).
3. **피드백 루프 연동**. `synthesize(..., calibration=…)`가 `overall_score += direction_bias`, `confidence *= confidence_scale`를 적용하고 `MarketPrediction.calibration`에 저장. `PredictionService`가 `accuracy_service`에서 보정을 받아 주입 → **채점→보정→다음예측→재채점** 루프가 닫힌다. 같은 `trend_core`를 채점·예측에 공유하므로 **측정한 정확도 = 실제 사용 예측의 정확도**.
4. **읽기 라우트 + UI**. `GET /api/v1/accuracy/track` → `AccuracyTrackReport`. `/accuracy` "예측 정확도·추적" 페이지: **SVG 듀얼라인 차트**(실제 vs 모델 누적수익 + 방향 **오답 마커**) + 채점표 + **자동 피드백 보정 카드**(보정값·등급·근거·"다음 예측 자동 반영" 배지). nav "정확도"(GaugeCircle).

## Consequences

- 사용자는 예측과 실제의 진행을 한 화면에서 본다. 라이브 검증: 1년 창 누적 실제 +205.6% vs 모델 +205.6%(겹침 — 강세장에서 모델이 100% 강세 유지해 매수보유와 일치), 적중률 69%(기저 69%), 차트에 **오답 93개 마커**로 시점별 적중/오답을 직관 표시. 하락 국면에선 두 선이 갈라진다(테스트로 검증).
- 자기개선 루프가 실제로 닫힌다. 라이브 예측이 보정을 carry: 245회 채점→방향 보정 +0.03·신뢰도 ×0.8 도출→확신도 0.62→0.50로 보수화(과신 교정), 방향 상승 미세 보정. 다음 채점이 이 보정 효과를 다시 평가.
- 정직성: 등급에 A를 두지 않고, 강세장의 음수 스킬이 국면 특성임을 명시. 별도 DB 없이 결정론 replay로 기록이 항상 최신. 결정론·표시전용·float 미사용 유지.
- 한계: 강세장에선 두 누적선이 겹쳐 시각적 디버전스가 적다(오답 마커로 보완). 보정은 유계라 급격히 바뀌지 않는다(안정성 우선).

## Update (2026-06-18b) — 확신도 상향(과소평가 교정)

확신도가 0.50으로 "동전던지기"처럼 보였는데, 이는 (a) BOK 매파(−)가 강세 추세(+)와 충돌해 net 점수가 작았고, (b) 보정이 신뢰도를 곱셈으로 깎았기 때문이었다. 그러나 모델의 **실제 방향 적중률이 69%**인데 확신도 50%는 오히려 과소평가다. 두 가지로 정직하게 상향: (1) 합성기 확신도 공식을 가팔게 하고 **주 신호(추세) 강도 보너스**(강도 1.0·정합 시 +0.12) 추가, (2) Calibration의 `confidence_scale`(곱셈 하향)을 **`confidence_target`(실현 적중률)**로 교체해, 명확한 방향 콜이면 확신도를 실현 적중률(≈0.69)에 **정합(블렌드)**시킨다. 결과: 라이브 확신도 0.50→**0.72**(강한 정합 추세 + 69% 실적중률 근거). 과신이면 끌어내리고 과소면 끌어올리는 양방향 캘리브레이션이라 정직성도 향상.

## Update (2026-07-21) — 방향별 확신도 앵커 + 실측 하한(floor)

두 가지 정직한 강화. (1) **방향별 오차 반영**: 상승콜과 하락콜의 실현 적중률은 다르므로
(`bull_target`/`bear_target`, 방향별 표본 ≥15일 때; 미달 시 전체 적중률로 폴백),
확신도 앵커를 풀드 평균이 아닌 **해당 방향의 실측 적중률**로 잡는다.
(2) **하한**: 블렌드 후에도 확신도가 앵커 아래로 내려가지 않도록 floor — 실측 ~60%
적중인 콜이 50% 미만("동전던지기")으로 표기되는 것은 캘리브레이션 오류이기 때문.
앵커가 0.5 미만이면(실측이 동전던지기 이하) 적용하지 않아 과신 인플레이션은 없다.
`/accuracy` 보정 카드에 방향별 앵커를 표시.

**근거(실측, ^KS11 7,287세션 replay).** 방향별 D5 실현 적중률은 **상승콜 64.3% vs
하락콜 44.8%**로 크게 비대칭이다(상태별: 상승추세 56.5%·기본롱 55.1%·확인약세 46.9%·
리스크오프 43.7%). 이전의 풀드 62% 단일 앵커는 상승콜을 과소·하락콜을 과대평가했다.
방향별 앵커는 이를 교정한다 — 대부분의 날(상승)은 실측 64%로 앵커되어 "동전던지기"를
벗어나고, 드문 하락콜은 실측 45%로 정직하게 낮게 표기된다(숫자를 억지로 50% 위로 올리지
않는다). 하락콜의 낮은 적중은 KOSPI 상승 드리프트 + 급락 후 기술적 반등의 구조적 결과이며
(ADR-029), 리스크오프 오버레이는 정확도가 아니라 **라이브 리스크 프레이밍**이 목적임을
유지한다. 병행 실험한 리스크오프 꼬리 처리 변형 2종은 held-out(최근 750세션)에서 개선이
없어 `trend_core`는 변경하지 않았다(과적합 회피).

## Alternatives Considered

- **실제 저장 예측만 채점(rejected as primary).** 표본이 적어(이번 세션 분) 시계열·보정이 빈약하다. 결정론 replay가 즉시 풍부한 기록을 준다(라이브 예측도 동일 신호라 일관).
- **예측 누적 점수 DB 테이블 신설(considered, not chosen).** replay가 항상 최신 기록을 재구성하므로 마이그레이션 복잡도를 피한다.
- **보정을 강하게/비유계(rejected).** 과적합·불안정 위험. 유계 보정으로 안정적 자기개선.
- **모델선=매수보유 대신 예측 목표가 라인(considered, not chosen).** 기대수익 크기 가정이 자의적이라, 검증 가능한 추종-전략 누적수익 + 오답 마커를 택했다.
